# Directorio Viajero (MVP Web)

Plataforma publicitaria y directorio de agencias de viajes verificadas en México.

## Estructura del Proyecto
- `index.html`: Página principal con buscador por destino y cuadrícula dinámica de agencias.
- `css/styles.css`: Hoja de estilos global responsiva.
- `data/agencias.js`: Base de datos modular de agencias anunciantes.
- `js/app.js`: Lógica de renderizado, ordenamiento por plan destacado y filtrado por destino.
- `pages/anunciate.html`: Landing comercial B2B con planes y formulario de registro.
- `pages/legal.html`: Términos de servicio, aviso de privacidad y deslinde de responsabilidad.
